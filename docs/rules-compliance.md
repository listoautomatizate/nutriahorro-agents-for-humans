## Optional items deliberately excluded

- Amazon Bedrock AgentCore deployment.
- AWS promotional credit redemption.
- Builder Center bonus blog posts.

The live demo link is optional under the rules, but nutrIAhorro includes it because it strengthens Technical Implementation and makes judging easier.

- Confirm the public app, GitHub repository, architecture diagram, and public video all open in a private browser window.
