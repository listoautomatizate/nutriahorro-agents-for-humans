# Privacidad, seguridad y limites

## Datos personales

El MVP debe utilizar un perfil de demostracion. Antes de manejar datos reales se necesita consentimiento informado, una politica de privacidad y una funcion para exportar y eliminar los datos de la persona.

La demostracion publica incluye un control para restablecer sus datos ficticios. Los tickets se analizan en dos pasos: primero se propone una lectura editable y solo despues de la confirmacion humana se modifica la despensa.

## Secretos

Las claves de AWS se guardan en el entorno local o mediante roles IAM. Nunca se incluyen en el repositorio, capturas, videos ni archivos de demostracion. El puente web protege su entrada con un token de servidor y su rol solo puede invocar el AgentCore Runtime especificado.

## Nutricion y alimentos

nutrIAhorro ofrece informacion general de bienestar y organizacion. No diagnostica, no prescribe dietas y no modifica tratamientos. Frente a alergias, embarazo, enfermedades, sintomas o metas clinicas deriva a un profesional habilitado.

Las fechas de consumo de la demo son estimaciones. La version productiva debe basarse en etiqueta, condiciones reales y fuentes oficiales. El pollo crudo se recomienda sellado y en el estante inferior para reducir contaminacion cruzada. Cuando existen varios lotes, el descuento usa primero el de vencimiento o compra mas antiguo y rechaza la operacion completa si no hay cantidad suficiente.

## Ofertas

La demostracion no afirma precios reales. Una futura integracion debe respetar los terminos de cada supermercado, mostrar fuente y fecha de consulta, y permitir que la persona confirme el local antes de comprar.
